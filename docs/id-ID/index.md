---
title: Layar kunci
description: Konfigurasikan layar kunci ARGVUS berbasis Hyprlock.
---

`argvus-lock` menyediakan konfigurasi Hyprlock dan pembantu tema. File yang dikemas berada di bawah `/usr/share/argvus/lock/config/` dan `/usr/share/argvus/lock/sh/`.

`argvus-power` dan layanan idle memicu aksi penguncian dan DPMS. Perubahan tema menghasilkan kembali tampilan layar kunci.
